# Screenshots

This folder contains UI screenshots referenced by `README.md`.

## Capture checklist

1. Sign in to EntraMap with a demo tenant account.
2. Capture these views at 1440px width:
   - `mainScreen.png` — homepage with search and graph visible
   - `searchObjects.png` — object type tabs in the search panel
   - `userSearch.png` — user search results
   - `groupImpact.png` — group detail panel with Impact tab open
   - `impactHtmlExport.png` — Export impact HTML action in the group detail panel
   - `permissionLightbox.png` — permission check lightbox after sign-in
3. Keep filenames aligned with the README image references.

Screenshots are documentation assets only and are not required for application runtime.
